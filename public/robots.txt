# =====================================================================
# seanfinch.com
#
# Three tiers below, deliberately different:
#   1. Search engines        - full site, thumbnails only for images
#   2. User-triggered AI     - full site (a human explicitly asked)
#   3. AI training/indexing  - professional pages only
#
# TWO MECHANICS THAT TRIP PEOPLE UP, both relied on here:
#   * Rules are NOT inherited. A crawler that matches a named group
#     below ignores "User-agent: *" completely, so every group has to
#     be self-contained even where that means repeating lines.
#   * Within a group the LONGEST matching path wins, not the first.
#     That is why "Disallow: /" can sit under a list of Allow rules.
# =====================================================================


# ---------------------------------------------------------------------
# 1. SEARCH ENGINES - Google, Bing, DuckDuckGo, etc.
# Full access to pages. For images, only the 500px thumbnails are
# crawlable: enough for Google Images, useless for reprinting. The
# full-res originals and the 2000px lightbox versions stay out.
# ---------------------------------------------------------------------
User-agent: *
Allow: /
Disallow: /photography/
Allow: /photography/_derived/thumb/

# /music retired Sept 2026 - serves a hard 404 + X-Robots-Tag: noindex.
# The Disallow stays commented until Search Console confirms it has left
# the index; blocking the crawl now would stop Google from ever seeing
# the 404 it needs in order to de-index the URL.
# Disallow: /music


# ---------------------------------------------------------------------
# 2. USER-TRIGGERED AI FETCHES - full access, on purpose.
# These fire only when a real person asks an assistant to look at this
# site ("what's on seanfinch.com?"). That person is very likely a
# recruiter. Blocking these would break the exact moment this site
# exists for, so they get everything.
# ---------------------------------------------------------------------
User-agent: ChatGPT-User
User-agent: Claude-User
User-agent: Perplexity-User
User-agent: Applebot
Allow: /


# ---------------------------------------------------------------------
# 3. AI TRAINING & ANSWER-ENGINE CRAWLERS - scoped to the professional
# pages. These build the model's picture of who I am, so the resume
# surface is open on purpose. Photography is excluded: it adds nothing
# to a "who is Sean Finch" answer, and full-res creative work entering
# a training corpus is a one-way door.
#
# /assets/ is allowed so the rare JS-rendering crawler can boot the app.
# ---------------------------------------------------------------------
